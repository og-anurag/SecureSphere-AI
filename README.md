# 🛡️ SecureSphere AI

> **Multi-Agent AI Powered Digital Security Assistant**

SecureSphere AI is an intelligent cybersecurity platform that helps users stay safe from modern cyber threats using specialized AI agents.

---

## 🚀 Features

- 🌐 Phishing Website Detection
- 📧 Scam Email Detection
- 📱 Malicious APK Analysis
- 🔳 Fake QR Code Detection
- 💳 Payment Fraud Detection
- 🤖 AI Risk Scoring
- 🛡️ Security Recommendations

---
